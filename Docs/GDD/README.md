## 🎯 Vision du Projet

**Project TDB** est un jeu de combat tactique au tour par tour fusionnant :
- ⚔️ **Combat tactique** sur grille hexagonale
- 🃏 **Deck building** avec système de cartes
- 📊 **Gestion de ressources** (PA, PM, Santé, Rage, Émotion)
- 🎭 **Système d'émotions** unique affectant les compétences

## 🎮 Pilliers du Gameplay

1. **Décisions Tactiques** - Chaque mouvement compte
2. **Synergie de Deck** - Construisez des combos puissants
3. **Gestion de Ressources** - Équilibrez PA, PM et émotions
4. **Progression Significative** - Chaque victoire vous rend plus fort
